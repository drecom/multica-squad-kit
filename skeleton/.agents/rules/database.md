# DB を変える作業

このファイルは、DB を持つリポジトリだけに置きます。`paths` を実際の対象に置き換え、[リポジトリの指示](../../AGENTS.md)の対応表に行を足します。箇条書きは記入の例です。プロジェクトの決まりに合わせて書き換え、合わない行は削除します。

## 変えてよいものと順序

- 出荷済みのマイグレーションは書き換えません。直すときは、新しいマイグレーションを足します
- 新旧のアプリが同時に動く間も壊れない順で変えます。列の削除と名前の変更は、古いアプリが止まったあとのリリースに分けます
- 本番や共有の DB には接続しません。流す前に接続先を確認します
