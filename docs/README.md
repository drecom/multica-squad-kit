# 設計の文書の索引

`docs/` にある設計の文書を、変えるものごとに並べる。文書の題と、何が書いてあるかを 1 行で示す。

主に読む人は、この原本を変える人である。ほかにも読む人がいる文書は、説明の中に書く。使う人への手順は[導入と更新](../manual.md)に、変更の進め方は [CONTRIBUTING.md](../CONTRIBUTING.md) にある。

設計の文書を足したら、この索引にも 1 行を足す。載っていない文書があると、リンクの検査が落ちる。
