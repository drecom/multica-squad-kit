# 端末に依る確認の行き先

端末に依る確認を 1 件ずつ、層とケースへ対応させる。置かない確認は、置かない理由を書く。

この文書は [terminal-tests.md](terminal-tests.md) の付表である。層、補助、ケースの番号（T01 から T27）の意味は、そちらに従う。

## 目的と範囲

確認を黙って消さず、弱めずに層とケースへ割り当てていることを、レビューと実装で照合できるようにする。対象は、補助のケースと確認する性質、製品のテストの端末に依る部分である。

製品のテストの行の番号は、それぞれのテストのファイルの行である。

## 補助のケースの表

補助の回帰テストのケースを、確認の種類ごとにまとめる。

| 確認の種類 | 条件 | ケース | ケースが確認すること |
| --- | --- | --- | --- |
| 出力の量と出す先（stream） | 出力が 0・16・131072 バイト。出す先の組み合わせが 6 通り | T01 | 同じ量と組み合わせで、出力が決めたバイトと同じで 0 を返す |
| 読み始める前の終了（before-read） | 読み始める前にコマンドが終わる | T02 | `--hold-read` で読み始めを止め、出力をすべて受けて 0 を返す |
| 答えのあとの出力（after-empty、after-answer） | 答えのあとに出力して終わる。答えの直後に出力して終わる、出力が空のときも同じ | T03 | 答えのあとの出力と空の出力が、決めたバイトと同じで、エコーを含む |
| 標準入力がファイル（input-file） | 標準入力がファイル | T01 | 標準入力がファイルの組み合わせで、出力が決めたバイトと同じ |
| 標準入力が別の端末（input-tty） | 標準入力が別の端末 | T01・T16 | 端末の組み合わせで出力が同じ。始める前の入力が届かない |
| 区切りをまたぐ問い（split-prompt） | 問いが 4096 バイトの区切りをまたぐ | T04 | 区切りをまたぐ問いに 1 回だけ答える |
| 来ない問い（no-prompt） | 問いを出さずに 7 で終わる | T05 | 125 を返し、来なかった問いを出し、読んだ出力が残る |
| 終了コード（exit-code） | コマンドが 7 で終わる | T06 | 7 を返す |
| シグナル（signal） | コマンドが TERM で終わる | T07 | 143 を返す |
| 出力を閉じたコマンド（eof-before-exit、one-eof、eof-timeout） | 出力を閉じてから終わる。出力を閉じたまま終わらない | T08 | 出力を閉じて生きたままのコマンドが 7 で終わり、出力をすべて受ける。終わりは T08 の解放で決める |
| 子孫の出力（descendant-output） | コマンドが終わったあとに子孫が書く | T09 | 子孫の出力を受け、0 を返し、`ps` にプロセスが残らない |
| 子孫が残る（descendant-timeout） | 子孫が出力を持ったまま残る | T10 | 保持のパイプを閉じて残る子孫が KILL され、`ps` に残らない |
| TERM を無視するコマンド（term-resistant） | コマンドが TERM を無視する | T14 | 補助への TERM で 143 を返し、`ps` にプロセスが残らない |
| 読み取りの例外（read-error） | 読み取りで例外が起きる | T18 | 125 を返し、C が残らず、`/dev/fd` が前後で同じ |
| 起こせないコマンド（spawn-error） | コマンドを起こせない | T15 | 127 を返し、端末と FIFO の fd が残らない |
| 入力が詰まる（input-blocked） | 答えを送る間に入力が詰まる | T17 | 大きな答えと大きな出力が同時でも止まらずに終わる |
| 書きかけの答え（partial-input） | 答えが 1 バイトずつしか送れない | T18 | 書きかけのあとに残りを送り、0 を返す |
| 答えの送信の例外（input-error） | 答えの送信で例外が起きる | T18 | 125 を返し、C が残らず、`/dev/fd` が前後で同じ |
| EIO（eio） | Linux の EIO | T01・T19 | マークのあとは読まないので EIO を受けない。T01 が両方の OS で通る |
| 端末の入力の bash（bash-child） | 端末の入力の bash がコマンドを起こして終わる | T16・D | 始め方の確認と、D の層のセットアップの対話で確認する |

終了コードは、終わり方ごとに分ける。通常の終わりはコマンドの値、始められなかったときは 127、補助が止めたときは 125、補助への TERM は 143 を返す。

## 補助の確認の文

補助の回帰テストが確認する性質を、ケースへ対応させる。

| 確認する性質 | 条件 | ケース | ケースが確認すること |
| --- | --- | --- | --- |
| 順序の合図 | 順序の合図の fd から 1 バイト読む | T02・T08 | 合図は FIFO で渡し、読んだあとに次の手順へ進む |
| 答えの届き方 | コマンドが答えを読む | T03・T16・T20 | 答えが 1 回だけ届き、エコーが問いの全文のあとに出る |
| 読み残し | 出力側を閉じる前 | T01・T09 | マークより前の出力をすべて受け、決めたバイトと同じ |
| 終了コード | どのケースも | T01–T27 | 各ケースの期待の値と同じ |
| 回収 | どのケースも | T12・T14・T23 | `ps` にプロセスが残らず、見張りの FIFO が EOF になる |
| 端末の fd | 補助が終わったあと | T15・T23 | `/dev/fd` が前後で同じ |
| 出力のストリーム | 補助が終わったあと | T23 | `/dev/fd` が前後で同じで、開いたファイルを閉じている |
| コマンドのグループ | 補助が終わったあと | T09–T12・T14 | `ps` に C のプロセスが残らない |
| 入力のファイル | 標準入力をファイルで渡す | T23 | `/dev/fd` が前後で同じ |
| 止められたコマンド | コマンドが止められる。TERM を無視する | T11・T14 | 止められたコマンドと TERM を無視するコマンドが残らない |
| 入力の詰まり | 入力が詰まりうる | T17 | 詰まらずに送り切って終わる |
| 例外の前の出力 | 読み取りで例外が起きる | T05・T18 | 例外の前に読んだ出力が出力のファイルに残る |
| 例外の診断 | 例外が起きる | T18 | 125 を返し、例外の種類を標準エラー出力に書く |
| 読み始めの順序 | 順序を決めるケース | T02 | `--hold-read` の FIFO の EOF のあとに読み始める |
| 出力を閉じたコマンドの終わり | 出力を閉じたコマンド | T08 | 出力を閉じたコマンドの終わりを待ち、7 を返す |
| 問いのない終わり | 問いを出さずに終わる | T05 | 125 を返し、出力のファイルがコマンドの書いたバイトと同じ |
| 成功したケースの出力 | 成功したケース | T01・T03・T04 | 出力が決めたバイトと同じ |

## 外す確認

次の確認は、確認する対象を持たないので置かない。どれも、時間と環境に依る作りを確認するためのものである。

| 外す確認 | 外す理由 | 代わりに確認すること |
| --- | --- | --- |
| 壁時計と単調時計（clock） | 補助が時計を持たない | 補助のファイルに時計の呼び出しがないことを検索で確認する |
| 時間切れと診断の JSON | 補助が期限を持たない | 終わり方ごとの値を T05、T10–T15 で確認する |
| 通常の形の終了コード | 通常の形を持たない | 補助はいつもコマンドの値を返す（T06） |
| 失敗時の途中の出力の保存 | 失敗時の記録は解決に数えない | 読んだ出力は出力のファイルに残る（T05） |
| 空の select の順 | 終わりをマークで決めるので、結果に効かない | 答えのあとの出力（T03） |
| ケースの表の整合 | ケースの表を持たない | ケースはテストのスクリプトに直に書く |
| 大きさの変化の待ち | スタブの大きさは待たずに効く | 描き直した画面（B） |
